Notes and process

How this works

  • Each project runs its tests in GitHub Actions on every push and again every night.
  • After each run it publishes a small status.json next to its report. This page fetches those files live. There is no server and no stored data.
  • A result older than about a day and a half is flagged as stale, so a quietly broken nightly run cannot look healthy.

Source for this page and the status format: yeshallbeasgods.github.io.
